# Research with a clear boundary.

BeepBoop is an independent, experimental Discord assistant for research and data
analysis. It can search a saved library, find public sources and datasets, run
analysis in an isolated environment, and create charts and geographic maps.
Its research areas include cybersecurity and finance. Features and access are
limited during the beta.

## Know what you share

A server research thread is a shared conversation. A private DM uses a separate
personal research workspace, but the operator and the services that deliver it
can still process its contents. AI responses can be wrong; verify sources and
results before relying on them.

## Access and support

Using BeepBoop requires an eligible Discord account, approved access and a linked
Google sign-in. Some features require additional permissions. Installing the app
does not automatically grant access to the research service.
